# FEINAL

- `quiz/` – שאלון היכרות קצר לליד (2-3 דקות). קישור עם פרטים מראש: `quiz/#admin`.
- `program/` – שאלון פרוגרמה ללקוח שחתם. יצירת קישור עם פרטים מראש: `program/#admin`.
- `sign/` – חתימה על ההסכם מהטלפון. יצירת קישור ללקוח: `sign/#admin`.

התשובות נשלחות אוטומטית למייל, כולל PDF על נייר המכתבים וקישור לצפייה מלאה.
קבצי מדידה, לוגו וספר מותג נשלחים במיילים נפרדים עם הקובץ המקורי.
הקבצים עצמאיים. לא נשמר כאן מידע על לקוחות.
